# Frontend Verification Checklist: AI Tarot Application

**Purpose**: AI 타로 프론트엔드 애플리케이션 프로덕션 배포 전, 기술 헌장 규칙 및 사용자 시나리오 명세 충족 여부를 확인하는 최종 상호 정밀 검증용 체크리스트입니다.
**Feature**: `/specs/tarot/frontend/spec.md`

---

## 1. 인증 및 접근 제어 (Auth Guard Layer)
- [ ] **CHK-FE-001** 브라우저 로컬 스토리지 및 세션 쿠키가 완전 소멸된 비로그인 상태에서 `/tarot/main` 등 모든 하위 서비스 코어 경로 강제 진입 시 예외 없이 `/login` 주소로 튕겨 나가는가? (태스크 연동: `T009`)
- [ ] **CHK-FE-002** 계정 정보 입력 후 로그인이 적절히 통과되었을 때 유저 인증 토큰 세션 정보가 Zustand 스토어 영역에 누락 없이 수립 및 바인딩되는가? (태스크 연동: `T007`)

## 2. 고민 입력 검증 (Validation Guard Layer)
- [ ] **CHK-FE-003** 고민 입력TextArea 서식에 10자 미만의 짧은 텍스트를 입력했을 경우 하단 "운명의 카드 선택하기" CTA 버튼이 불투명도 50%의 명확한 비활성화(Disabled) 그래픽 톤을 유지하는가? (태스크 연동: `T014`)
- [ ] **CHK-FE-004** 스페이스바 공백 문자나 무의미한 줄바꿈 엔터 키만 도배하여 의도적으로 10자 벽을 우회하려고 시도할 때, Zod 검증 엔진이 이를 파싱 차단하고 제출 거부 팝업 토스트를 뿜어내는가? (태스크 연동: `T012`, `T013`)
- [ ] **CHK-FE-005** 한계 도달 수치인 500자를 가득 채워 타자 입력을 가져갈 때, 추가 기입이 원천 잠금 처리되며 실시간 글자수 스케일러가 `500 / 500` 포맷을 안전하게 한계 도출해내는가? (태스크 연동: `T013`)

## 3. 카드 인터랙션 및 상태 관리 (Motion & Tarot Selection State)
- [ ] **CHK-FE-006** 메인 22장 카드 풀 스프레드 배열 내 개별 카드 오브젝트에 마우스 호버(Hover) 시, 프레임 드롭 현상 없이 네이티브 반응으로 부드러운 스케일 업 및 보라색 발광 테두리 무드가 연출되는가? (태스크 연동: `T015`, `T016`)
- [ ] **CHK-FE-007** 특정 카드를 정밀 타격해 클릭했을 때 제자리 3D 카드 뒤집기(Flip) 모션이 유연히 발동되며 중앙에 순차 선택 스탬프 배지(`1`, `2`, `3`)가 즉시 마킹되는가? (태스크 연동: `T017`)
- [ ] **CHK-FE-008** 이미 번호가 기입된 활성화 카드를 다시 한번 누르면 온전히 단일 해제 컴포넌트화 처리가 되며, 나머지 남아있던 타로 카드들의 할당 번호 순서 배열이 유기적으로 당겨져 재정렬되는가? (태스크 연동: `T017`)
- [ ] **CHK-FE-009** 정확히 서로 다른 카드 3장 마킹이 종료되는 찰나, 마우스 포인터 핸들러가 전면 비활성화(Locked)되며 추가 클릭이 완전 봉쇄된 후 대기 라우터로 지연 없이 튕겨 나가는가? (태스크 연동: `T017`)

## 4. 로딩 및 장애 처리 (Resilience & Error Handling)
- [ ] **CHK-FE-010** AI 해석본을 수신 대기하는 `/tarot/loading` 스크린 가동 와중에 유저가 브라우저 뒤로가기 제어나 새로고침 액션을 유발하면 네이티브 단절 방지 경고창 오버레이가 앞면을 방어해내는가? (태스크 연동: `T022`)
- [ ] **CHK-FE-011** 백엔드 망 마비 혹은 LLM 응답 연동 마비 상태를 가정하여 15초 타임아웃을 강제 오버시켰을 때, 무한 로딩 지연 현상 없이 정의해 둔 시스템 경고 에러 복구 모달이 정시에 돌출되는가? (태스크 연동: `T021`, `T023`)
- [ ] **CHK-FE-012** 인프라 장애 에러 팝업 모달의 확인 상호작용 인터랙션을 클릭했을 시, 고여있던 로딩 세션 상태값을 초기화하고 입력 첫 화면인 메인 뷰 페이지로 예외 없이 클린 복귀를 시켜주는가? (태스크 연동: `T023`)

## 5. 결과 렌더링 및 마이페이지 이력 제어 (Output View & Cache Optimistic Update)

- [ ] **CHK-FE-014** 마이페이지 축적 리스트에서 특정 상담 이력 'X' 삭제 버튼을 트리거하면 백엔드 서버 DB 영구 처리가 완결되기 이전 시점이라 할지라도 UI 목록에서 해당 카드 노드가 인스턴트하게 지워지는가? (태스크 연동: `T028`)
- [ ] **CHK-FE-015** 만약 사후에 삭제 네트워크 요청 실패 수신(500) 응답이 날아오면, 낙관적으로 선 제거했던 목록 카드가 직전 상태 스냅샷 데이터 기반으로 원래대로 정상 롤백(Rollback)되어 자리를 복구하는가? (태스크 연동: `T028`)

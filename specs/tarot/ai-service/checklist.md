# AI-Service Verification Checklist

**Purpose**: AI 추론 엔진 및 RAG 서비스 배포 전 기획 명세서 정책 사양 및 기술 헌장 규칙에 충족하는지 무결성을 최종 검증하는 인프라 마스터 체크리스트입니다.  
**Feature**: `/specs/tarot/ai-service/spec.md`

---

## 1. Vector Retrieval & RAG Infrastructure

- [ ] **CHK-AI-001** FastAPI ASGI 웹 어플리케이션 기동(Uvicorn 부팅) 초기 세션 단계에서 사전에 빌드 가공된 로컬 FAISS Index 바이너리 파일(`.index`)이 메모리에 누락 없이 고속 적재되는가? (태스크 연동: `T007`, `T008`)
- [ ] **CHK-AI-002** 유저 카드 ID 입력값에 매칭되는 로컬 벡터 검색 수행 결과 정보가 78장 원천 데이터 문서 가이드 소스의 타로 의미와 논리적으로 완벽히 일치 연동하는가? (태스크 연동: `T004`, `T008`)
- [ ] **CHK-AI-003** 동시 다발적인 가중 부하 통신 환경 기준에서 로컬 인메모리 FAISS 단독 코사인 유사도 검색 레이턴시가 성능 목표치인 **2ms 이하**를 명확히 사수해내는가? (태스크 연동: `T008`)
- [ ] **CHK-AI-004** OpenAI API 연동을 통해 빌드 가공 완료된 타로 임베딩 벡터 차원 스펙 데이터가 1536차원의 고유 차원수 규칙을 일관되게 유지 형성하고 있는가? (태스크 연동: `T006`)

## 2. Validation & Prompt Security Shield

- [ ] **CHK-AI-005** Pydantic v2 유효성 스키마 가드 판단 하에, 폼 서식을 벗어난 범위의 불량 카드 ID나 자수 한계 미달 요청 인입 시 OpenAI 원격 호출 스레드를 할당하지 않고 즉각 `422 Unprocessable Entity` 에러를 뿜어내는가? (태스크 연동: `T009`, `T014`)
- [ ] **CHK-AI-006** 사용자의 인입 고민 본문 내부에 시스템 마스터 프롬프트 규칙 공개나 역할 변경을 강제 강요하는 악성 인젝션 우회 문구 포착 시, 쉴드 레이어가 작동하여 `400 Bad Request` 에러 코드로 패킷을 원천 드롭 차단해주는가? (태스크 연동: `T016`)
- [ ] **CHK-AI-007** 유저가 작성한 고민 데이터 내용과 시스템 고유 영속 지시 프롬프트 영역 간의 경계면 혼선을 방지하기 위해 특수 문자 구분자(`---`, `###`) 가드를 통한 격리 격벽화가 완벽히 완수되는가? (태스크 연동: `T015`)

## 3. RAG Inference & Schema Sync

- [ ] **CHK-AI-008** LangChain 프레임워크 기반 RAG 추론 파이프라인이 먹통 없이 원활히 구동되며, 최종 수신되는 LLM 결과 패킷 구조가 `prompt-spec.md`가 선언한 4단 구조화 JSON 스키마 규격을 빈틈없이 유지 렌더링하는가? (태스크 연동: `T013`)
- [ ] **CHK-AI-009** 생성 성공하여 최종 클라이언트로 리턴해 주는 출력 데이터 JSON 상부 최상위 노드 구조 내부에 사후 추적용 프롬프트 식별자 버전 명세 값(`"prompt_version": "v5.0.0"`)이 무결하게 고정 출력되어 나오는가? (태스크 연동: `T009`, `T010`)
- [ ] **CHK-AI-010** 원격 OpenAI 네트워크망에 지연 붕괴나 순시 에러가 발생했을 때, 하드 무한 루프에 빠지지 않고 지정된 Exponential Backoff 메커니즘 기반 비동기 자동 재시도 정책이 정상 구동 복구 흐름을 만들어내는가? (태스크 연동: `T012`)
- [ ] **CHK-AI-011** 프롬프트 지침에 의거하여, FAISS로 검색 노출된 Retrieval Context 지식 가이드 정보 외의 영역에 대해 LLM이 독단적으로 상상하여 살을 붙이지 않는 정보 생성 최소화 정책이 유지되는가? (태스크 연동: `T011`)

## 4. Safety Guardrail Policy

- [ ] **CHK-AI-012** LLM 추론 완료 기점의 정형화 4단 JSON 분문 내역 중 특정 밸류 스트링 노드 영역에서 욕설이나 비속어, 혐오 유도 텍스트가 탐색될 시, 가드레일 필터가 이를 정상 포착하여 반환을 차단하는가? (태스크 연동: `T017`)
- [ ] **CHK-AI-013** 결과 본문 문장 구조 내부에서 자해를 조장하거나 혹은 절망적인 미래 단정, 공포 분위기 조성 표현이 유출될 징후 포착 시 세이프티 아웃풋 모듈이 발동하여 시스템 안전 에러 코드를 전이 트리거하는가? (태스크 연동: `T017`)
- [ ] **CHK-AI-014** 비즈니스 법적 리스크 방지 선언에 의거하여, 타로 결과물이 실제 의사의 진단이나 법률 전문가의 가이드, 투자 종목 추천 등의 전문 권고 오판을 유도하는 문맥을 담았을 시 예외 없이 최종 출력을 격리 드롭 차단하는가? (태스크 연동: `T017`)
